# Map and Images

Приложение на React Native (Expo) с картой OpenStreetMap и изображениями, привязанными к маркерам.

Карта реализована через `react-native-webview` + Leaflet + тайлы OpenStreetMap (вместо
`react-native-maps`, который на Android требует Google Maps API key и нативной сборки).

## Запуск

```bash
npm install
npx expo start
```

Далее откройте проект в Expo Go на устройстве.

## Функциональность

- Долгое нажатие по карте добавляет маркер (автоимя «Точка N»).
- Нажатие на маркер на карте открывает экран деталей.
- На экране деталей: координаты, дата создания, список изображений.
- «Добавить изображение» — выбор нескольких фото из галереи (`expo-image-picker`).
- Удаление отдельного изображения.
- Удаление маркера вместе с изображениями (с подтверждением).
- Навигация назад к карте (кнопка в шапке и кнопка «Вернуться к карте»).
- Обработка ошибок: загрузка карты/тайлов, сообщения из WebView, права доступа,
  исключения image picker, отсутствующий маркер, ошибки навигации.

## Структура

```
app/
  _layout.tsx          корневой Stack + провайдер маркеров + ErrorBoundary
  index.tsx            экран карты
  marker/[id].tsx      экран деталей маркера
components/
  Map.tsx              WebView + Leaflet + OSM
  ImageList.tsx        сетка изображений с удалением
  ErrorBanner.tsx      сообщение об ошибке
context/
  MarkersContext.tsx   состояние маркеров (useReducer + Context)
lib/
  mapHtml.ts           HTML/JS карты для WebView
types.ts               типы и валидация сообщений из WebView
```

## Ограничения

- Состояние хранится в памяти: после перезапуска приложения маркеры и изображения
  пропадают (персистентность в ТЗ не требуется).
- Для загрузки карты нужен интернет: библиотека Leaflet подключается с unpkg,
  тайлы — с `tile.openstreetmap.org`.
- Используется публичный тайл-сервер OSM; для продакшена нужен собственный провайдер
  тайлов согласно [политике OSM](https://operations.osmfoundation.org/policies/tiles/).
